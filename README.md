# TT Marathon Training App

Telefoonvriendelijke PWA voor je TT Marathon-schema richting 4 uur.

## Gratis online zetten via GitHub + Vercel

1. Maak een gratis GitHub-account aan.
2. Maak een nieuwe repository, bijvoorbeeld `tt-marathon-training-app`.
3. Upload alle bestanden uit deze map naar die repository.
4. Maak een gratis Vercel Hobby-account aan.
5. Klik in Vercel op **Add New > Project**.
6. Kies je GitHub-repository.
7. Laat de standaardinstellingen staan:
   - Framework preset: Vite
   - Build command: `npm run build`
   - Output directory: `dist`
8. Klik op **Deploy**.

Daarna krijg je een gratis URL van Vercel.

## Op je telefoon zetten

### iPhone
1. Open de Vercel-URL in Safari.
2. Tik op delen.
3. Kies **Zet op beginscherm**.

### Android
1. Open de Vercel-URL in Chrome.
2. Tik op het menu met drie puntjes.
3. Kies **App installeren** of **Toevoegen aan startscherm**.

## Lokaal testen

```bash
npm install
npm run dev
```
